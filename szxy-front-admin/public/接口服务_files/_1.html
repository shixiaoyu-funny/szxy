概述

服务简介

本服务为用户提供访问地名相关数据的API接口，即开发者可利用该服务提供的接口获取中国·国家地名信息库相关的公开数据。

本服务提供的API接口包括：

l  行政区划搜索

l  地名搜索

l  地名详情获取

l  同名区划统计

l  同名类别统计

l  同音区划统计

l  同音类别统计

使用说明

本服务所描述的请求方式包括Get和Post两种，具体参考各接口的【请求方式】说明，各个接口的相应报文正文返回格式为JSON数据格式。本服务中所涉及的地理空间坐标均采用2000国家大地坐标系（CGCS2000），并以经纬度的数值表示。

调用示例

例如：调用【地名搜索】接口，查询2018年版中北京市范围名称包括“故宫”的地名数据，其请求的url如下：

https:// dmfw.mca.gov.cn /9095/stname/listPub

请求的GET参数如下：

{

"page":1,

"size":10,

"code":"11",

"stName":"故宫"

}
