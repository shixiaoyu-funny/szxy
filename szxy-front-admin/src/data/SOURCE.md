# 台湾省静态区划数据说明

- 文件：`taiwanRegions.json`
- 用途：民政部国家地名信息库 `xzqh/getList` **不返回台湾省下级**，管理端省市区联动本地补全。
- 数据范围：台湾地区 6 个直辖市 + 3 个市（含完整区列表）+ 13 个县（仅到县级，第三级乡/镇/市未列入）。
- 整理依据：项目对话中提供的公开资料清单（注明参考百度百科等），**非**民政部接口原文。
- 代码：本地合成 `71xxxxxxxxxx`，仅用于前端级联 value，不与民政部官方码一一对应。
- 生成：`node scripts/gen-taiwan-regions.mjs`
