# 数智乡约 —— 软件功能说明（用户手册）

> AI 驱动乡村振兴服务平台。面向游客/农户/村长/管理员四类角色，提供乡村景点浏览、农户入驻、村务管理、商品交易与 AI 智能助手等功能。

## 一、系统概述

「数智乡约」是一个基于 AI 的乡村振兴服务平台，采用前后端分离架构：

- **用户端**（`szxy-front-user`）：面向游客、农户、村长，提供景点/乡村浏览、搜索、评论、点赞、收藏、购物、订单、钱包、AI 对话、农户/村长入驻申请与村务管理。
- **管理端**（`szxy-front-admin`）：面向管理员，提供农村/景点管理、农户建档、村长任命、准入审批、用户管理、数据报表。
- **服务端**（`szxy-backend`）：Spring Boot RESTful API，统一鉴权、业务处理、数据持久化与消息队列。

四类角色权限：

| 角色 | 说明 | 主要能力 |
|---|---|---|
| 游客 | 注册即得 | 浏览、搜索、评论、点赞、收藏、AI 聊天、购物、申请农户 |
| 农户 | 管理端建档 | 游客全部 + 本村新增景点、我的村/景点、卖家订单、申请村长 |
| 村长 | 管理端任命 | 农户全部 + 本村农户管理、村长准入审批 |
| 管理员 | 预置账号 | 农村/景点 CRUD、农户建档、村长任命、准入终审、用户管理、报表 |

## 二、运行环境

- 后端：JDK 17 + Maven，端口 8099
- 前端：Node.js 20+ + Vite，开发端口见各项目 `vite.config.ts`
- 中间件：MySQL 8（3399）、Redis 7（6399）、RabbitMQ 3.12（5673）
- 数据库初始化：`szxy-backend/src/main/resources/db/xiangyue_full.sql`

## 三、用户端功能

### 1. 注册与登录
支持手机号验证码、邮箱验证码、账号密码三种方式登录/注册；登录后进入对应角色界面。管理员不可登录用户端（会提示前往管理端）。

### 2. 首页与浏览
- 优质农村 TOP10、热门景点 TOP10 轮播展示。
- 支持关键词搜索（农村/景点）。
- 游客无需登录即可浏览（可选登录识别身份）。

### 3. 景点详情与互动
- 景点详情、评论列表、门票/住宿商品购买。
- 评论（支持图片、评分、回复）、点赞、收藏（需登录）。

### 4. AI 智能助手「禾小智」
- 文本/图片多模态对话，支持景点推荐、乡村攻略、当季活动等。
- 未登录可匿名聊天（不保存记录）；登录后可保存会话、新建对话、浏览历史。

### 5. 商品交易
- 购物车、下单（支持余额支付）、订单管理（取消/退款/确认收货/核销）。
- 收货地址管理、钱包余额与充值（模拟）。

### 6. 农户/村长入驻
- 游客可申请成为农户（填写经营类型）；农户可申请成为村长。
- 申请进度在消息中心与个人中心查看。

### 7. 农户/村长村务
- 农户：本村新增景点、我的村、我的景点、卖家订单（发货/退款）。
- 村长：本村农户增改删、村长准入审批（初审）。

## 四、管理端功能

### 1. 登录
管理员账号密码登录（仅 role=4 可进入）。

### 2. 报表查询
农户总数、当日 UV/PV、粘性、当日新增景点/农村、近 7 天 PV/UV 趋势图。

### 3. 景点管理
景点分页、新增（含门票/住宿价格）、编辑、详情、删除。

### 4. 农村信息管理
农村分页、新增/编辑（省市区级联 + 经纬度自动回填 + 村长任命）、删除。

### 5. 农户与村长资质
- 全部农户列表、建档（默认密码 123456）、任命/更换村长。
- 农户准入审批、村长准入终审。

### 6. 用户管理
用户分页列表，按关键词/角色/状态筛选。

### 7. 个人中心
账户概览、编辑资料（含头像上传）。

## 五、典型操作流程

1. **游客浏览 → 注册**：打开用户端 → 浏览首页/景点 → 点击「登录/注册」→ 手机号验证码注册。
2. **游客申请农户**：个人中心 → 申请成为农户 → 管理员在管理端「农户审批」通过 → 成为农户。
3. **农户新增景点**：我的景点 → 新增景点 → 填写信息（含价格）→ 提交即可上架。
4. **农户申请村长**：个人中心 → 申请成为村长 → 村长初审 + 管理员终审 → 成为村长。
5. **下单支付**：景点详情 → 立即购买 → 确认订单 → 钱包余额支付 → 查看订单/核销。
6. **管理员管理**：管理端登录 → 农村/景点 CRUD、农户建档、村长任命、报表查看。
